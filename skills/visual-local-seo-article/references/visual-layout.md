# 視覚レイアウト・写真選定ガイド

## 写真の選び方

本文の主張を証明できる写真を優先する。会議記事ではテーブル、着席レイアウト、モニター、ホワイトボードが見える写真を選ぶ。レッスン記事では鏡と安全な動線が見える写真を選ぶ。ポップアップ・物販記事では入口、棚、可動テーブル、商品を置ける壁面や導線が見える写真を選ぶ。

次の写真は原則として避ける。

| 避ける写真 | 理由 |
|---|---|
| 暗い、傾きが強い、解像度が低い写真 | 清潔感と信頼性を損ねる。 |
| 実際に備わらない設備が主役の写真 | 誤認につながる。 |
| 人物の顔や顧客情報が許可なく写る写真 | プライバシー上の問題がある。 |
| 記事テーマと関係のない写真 | 読む流れを妨げる。 |

## 生成ビジュアルの役割

生成画像は、実在施設の代替ではなく、読者が利用シーンを想像するための**編集用イメージ**として使う。キャプションには「イメージビジュアル：記事テーマをもとに作成」と記載する。施設設備や周辺環境の説明には、実写または公式資料を使う。

同じ記事群では、次の要素をそろえる。

| 要素 | 推奨 |
|---|---|
| 比率 | 横長16:9。見出しと組み合わせやすい構図。 |
| 余白 | 左右どちらかに余白を取り、文字を載せても読める構図。 |
| 色 | 1店舗につきメイン1色、補助1〜2色。 |
| 人物 | 利用シーンを簡潔に示す人数。混雑を誇張しない。 |
| テキスト | 原則として入れない。見出しはドキュメント側で管理する。 |

## Googleドキュメント／DOCXの基本レイアウト

1. 先頭に小さなカテゴリラベルを置く。
2. タイトルを大きく表示し、短い導入またはメタ説明を添える。
3. ヒーロー画像を横長で配置する。
4. その直後に「この記事でわかること」の色付きボックスを置く。
5. 導入後に店舗の実写写真を置き、具体的な設備・空間をキャプションで説明する。
6. H2前後に適度な余白を取り、本文は一段落を長くしすぎない。
7. 比較・チェックリストは、見出しに近い位置で表にする。
8. 終盤に、最新情報の確認を促すCTAボックスを置く。

## 可読性の目安

| 項目 | 目安 |
|---|---|
| 本文 | 10〜11pt、行間1.2前後。 |
| H2 | 14pt以上。本文より明確に大きくする。 |
| タイトル | 20pt前後。2〜3行以内を目安に改行する。 |
| 表 | ヘッダーを濃色、本文を淡色の交互にして追いやすくする。 |
| キャプション | 8〜9pt、中央揃え、短く事実に限定する。 |
| 画像数 | 1記事あたり、ヒーロー1枚＋実写1枚を基本とする。 |

## 視覚チェック

DOCXをPDFに変換して、少なくとも各店舗1記事を確認する。次のどれかが満たせない場合は修正する。

- 1ページ目だけで記事テーマと読む価値が分かる。
- 写真の下に関係のあるキャプションがある。
- 表の文字が小さすぎず、ページをまたいでも読める。
- 本文が色面・見出し・写真で適切に分割されている。
- CTAが埋もれていない。
